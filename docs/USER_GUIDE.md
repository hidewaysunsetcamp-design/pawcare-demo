# PAWCARE かんたんガイド（v1.1.0）

ペットの毎日の記録と、病院に伝えたいことをまとめるアプリです。
病気の診断や「急いだほうがいいか」の判定はしません。心配なときは動物病院に相談してください。

---

## はじめに

1. スマホで PAWCARE を開きます
2. 「ペットを登録する」から名前・種類などを入れます
3. ホーム画面に追加しておくと、アプリのように使えます

**大事なこと**
- 記録はこのスマホの中だけに保存されます。ほかのスマホとは同期しません
- iPhoneでは「Safariで開いたとき」と「ホーム画面のアイコンから開いたとき」で記録が別々になります。**どちらか一方に決めて使ってください**
- 機種変更やデータ消去に備えて、ときどき「設定 → バックアップ」をしてください

---

## 毎日の記録

- ホームのボタンをタップするだけで、今の時刻で記録されます
- 時刻やメモはあとから直せます
- 「記録」タブで、過去の記録を見られます

---

## 予定・リマインダー

ワクチン・お薬・ノミダニ予防・通院・トリミングなどの予定を登録できます。

**登録のしかた**
1. ホームの「⏰ 予定」カード、または「設定 → 予定を管理する」を開く
2. 「＋ 予定」を押す
3. 種類・日時・くり返し（毎日／毎週／毎月／毎年）を選んで「追加する」

**終わったら「✓ 完了」**
- くり返しの予定は、次の日時に自動で進みます
- 「服薬」の予定を完了にすると、健康記録に「服薬」が自動で残ります

---

## 通知を受け取るには（カレンダー登録）

PAWCARE は**アプリから通知を送りません**。
通知は、スマホのカレンダーから届きます。

1. 予定の「📅 カレンダーに登録」を押す
2. iPhone：「iPhoneのカレンダーに追加」→ 表示された画面で「追加」
   Android など：「Googleカレンダーに追加」または「.ics で追加」
3. 予定の時刻にカレンダーから通知が届きます（ワクチン・健康診断は前日にもお知らせ）

**注意**
- アプリで予定の日時を変えたり、削除したりしても、**カレンダーの予定は変わりません**。カレンダー側も直してください
- カレンダーに登録しなかった予定は、アプリを開いたときに表示されるだけです

---

## 病院に情報を見せる（共有リンク・QRコード）

受診のとき、ペットのプロフィール・問診メモ・最近の記録を病院に見せられます。

**作り方**
1. 「緊急時」画面の「共有リンク・QRコードを作る」、または問診メモを作ったあとのボタンを押す
2. 選ぶもの
   - ペット
   - 最新の問診メモを入れるか
   - 健康記録の期間（入れない／24時間／3日／7日／30日）
   - 有効期間の目安（24時間／3日／7日）
3. 「リンクとQRコードを作る」

**見せ方**
- 受付でQRコードを読み取ってもらう
- または、リンクをコピーして LINE やメールで送る

**必ず知っておいてほしいこと**
- リンクを知っている人は、だれでも中身を見られます。**病院以外には送らないでください**
- 情報はリンクの中に入っていて、PAWCARE のサーバーには保存されません
- 送ったリンクは**あとから取り消せません**
- 有効期限は「画面に出さなくなる目安」です。完全に見られなくなるわけではありません
- 記録の期間が長いとQRコードが作れません。そのときは期間を短くするか、リンクで送ってください

---

## 困ったとき

| こんなとき | ためしてください |
|---|---|
| 記録が消えた・見当たらない | Safari とホーム画面アイコンの両方で開いてみる。バックアップから復元する |
| 通知が来ない | その予定を「カレンダーに登録」したか確認。スマホのカレンダー通知がオンか確認 |
| カレンダーに同じ予定が2つある | 登録を2回押した可能性があります。カレンダー側で1つ消してください |
| QRコードが出ない | 健康記録の期間を短くして作り直す |

## 動物病院スタッフの方へ

飼い主様から PAWCARE のリンクまたはQRコードを受け取ったときのご案内です。

**開き方**
- QRコードをスマホのカメラで読み取るか、リンクをタップしてください
- 「受診用サマリー」という画面が開きます。ログインや登録は不要です

**表示される内容**
- ペット情報（種類・品種・年齢・性別・体重・メモ）
- 問診メモ（飼い主様が選んだ場合）
- 健康記録（飼い主様が選んだ期間の食事・排泄・嘔吐・服薬などの記録）

**ご注意**
- すべて**飼い主様が入力した情報**です。診断や医学的な判断は含みません
- 閲覧専用です。この画面から内容を変えることはできません
- 「印刷する」ボタンで紙に残せます（カルテ添付用など）
- 情報はリンクの中にだけ入っており、PAWCARE 側には保存されていません。必要な場合は印刷などで院内に記録してください
- 「有効期限が切れています」と出たら、飼い主様に新しいリンクを作ってもらってください
- 「表示できません」と出たら、リンクが途中で切れている可能性があります。もう一度送ってもらうか、最新の Chrome / Safari で開いてください
