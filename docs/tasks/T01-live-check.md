# T01 公開サイトの動作確認
状態：未着手

## なぜ
クラウド側の作業環境からは github.io に接続できず、本番のページを一度も確認できていない。パソコンからは開けるので、本番で正しく動いているかを確かめたい。

## やること
1. https://hidewaysunsetcamp-design.github.io/pawcare-demo/ を Playwright（スマホの画面サイズ：iPhone 13 と Pixel 7）で開く。
2. 次を確認してスクリーンショットを撮る：
   - 画面下の「設定」に出るバージョンが、`js/app.js` の `APP_VERSION` と同じか（古ければ、キャッシュが更新されない原因を調べる）
   - `#/demo` でサンプルデータが入り、ホームにうちの子のイラストが表示されるか（画像が欠けていないか）
   - 今日のお世話の行をタップ→✓が付く／全部そろうとパーフェクト画面が出る
   - 飼い方（#/guide）、きせかえ（#/avatar）、緊急時（#/emergency）が開けるか
   - ブラウザのコンソールにエラーが出ていないか
3. `tests/e2e.py` の URL を本番に向けて全件実行できるなら実行する（ファイルは書き換えず、環境変数などで一時的に切り替える）。
