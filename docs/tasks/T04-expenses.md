# T04 費用の管理
状態：未着手

## なぜ
ペットノートPlusで評価されている機能。ごはん代・病院代・保険などを記録したい飼い主は多い。

## やること
- 新しい画面 `#/money`（ホームのタイルから開く）。費用の追加：日付・金額（円・整数）・種類（ごはん／おやつ／医療・病院／ワクチン・予防／トリミング／用品／保険／その他）・ペット・メモ。
- 月ごとの合計と種類ごとの内訳。グラフは簡単な横棒でよい（色だけで区別しない。数字も添える）。
- 受診の記録（`visits`）に金額を入れたら、費用にも出せるようにするかはオーナーに確認する（最初は別々でよい）。
- CSV書き出し、バックアップ（JSON）に含める。取り込み時の検証も足す。
- 費用は共有リンク・QRには入れない。

## 確認
- e2e に「費用を追加→月の合計に反映→編集→削除」「金額に数字以外を入れると保存できない」を足し、全件合格。

## 出すもの
ブランチ `feat/expenses` でプルリクエスト。
