# T03 写真つきの記録（端末内に保存）
状態：未着手

## なぜ
吐いた物・便・皮膚・発作の様子は、言葉より写真のほうが病院に伝わる。ペットノートPlusにもある。

## やること
- 記録の入力画面に「写真を追加」（最大3枚）。スマホのカメラ・写真から選べる `<input type="file" accept="image/*" capture>`。
- 写真は **IndexedDB** に保存する（localStorage は容量が足りない）。保存前に長辺1280px・JPEG品質0.8程度に縮める。記録には写真のidだけを持たせる。
- 記録の一覧に小さなサムネイル、タップで大きく表示。記録を削除したら写真も消す（スワイプ削除の「元に戻す」にも対応）。
- 写真は**共有リンク・QRには入れない**（サイズが大きすぎるため）。受診のときは自分の画面で見せる、と画面に書く。
- バックアップ（JSON書き出し）には写真を入れない形でよい。そのかわり「写真はバックアップに含まれません」と設定画面に明記する。（含める方法はオーナーに確認）
- 写真をAIで判定するような機能は作らない。

## 確認
- e2e に「写真を添付→一覧にサムネイル→削除で写真も消える」を足す（テスト用の小さな画像を tests/fixtures に置く）。全件合格。

## 出すもの
ブランチ `feat/photos` でプルリクエスト。容量の見積もり（写真1枚あたり・何枚くらいで端末の上限に近づくか）を本文に書く。
