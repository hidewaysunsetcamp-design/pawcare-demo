# T05 飼い方のめやすの出典チェック
状態：未着手

## なぜ
`js/care.js` の温度・湿度・ごはんなどの数値は一般的な目安として書いたが、出典を付けていない。外平先生（獣医師）の監修の前に、信頼できる資料と照らし合わせておきたい。

## やること
- `js/care.js` のすべての動物と、爬虫類・魚・小動物・鳥の品種について、温度・湿度・ごはんの記載を、信頼できる資料（獣医師会・大学・動物園水族館・メーカーの公式飼育ガイドなど。個人ブログは避ける）と照合する。
- 法令に関わる記載（アカミミガメの条件付特定外来生物、プレーリードッグの輸入禁止、ヨウム・アジアアロワナのワシントン条約、メダカのレッドリスト）が今も正しいか確認する。
- 結果を表にまとめる：項目／今の記載／資料の記載／出典URL／判定（一致・要修正・資料なし）。

## 出すもの
- `docs/research/care-sources.md` をブランチ `research/care-sources` でプルリクエスト。
- **`js/care.js` は直さない**（直す案は表に書くだけ。監修の前にオーナーと外平先生が決める）。
