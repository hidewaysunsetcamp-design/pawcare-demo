# T02 体温の記録
状態：未着手

## なぜ
ペットノートPlusにあり、PAWCAREにない機能の1つ。受診のときに体温の記録を見せられると役に立つ。

## やること
- 記録のカテゴリに「体温」を追加（id は `bodytemp`。絵文字は温度・湿度と同じ🌡️になるので、ラベルの文字と色で区別する）。値は ℃ で小数1桁（例 38.6）。入力は 30.0〜45.0 の範囲だけ受け付ける。
- 体温は「記録」画面・健康手帳・病院に渡すQRの要点（共有リンク）・CSV書き出しに出す。体重と同じ扱いを参考にする（`weight` の実装を探すと早い）。
- **体温が高い／低いといった判定や色分けはしない**（診断になるため）。数値と日時を並べるだけ。
- 犬・猫・うさぎ・フェレットなど体温を測ることがある動物のワンタップ記録に入れるかはオーナーに確認する（最初はワンタップに入れず、「日時・メモを入力して記録」から選べる形にする）。
- 共有リンクを受け取った側の検証（`sanitizeShared` など）に、体温の値の検証を足す。

## 確認
- e2e に「体温を記録→記録画面とQRの要点に出る」「範囲外の値は保存できない」「共有リンクの体温に文字列を入れても画面に出ない」を足し、全件合格。

## 出すもの
ブランチ `feat/temperature` でプルリクエスト。
