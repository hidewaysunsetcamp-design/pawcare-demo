# 独自アドレス（ドメイン）への引っ越し手順（ことぽすと）

状態：2026-11-19 取得済み（kotopost.jp、Whois公開代行あり・自動更新あり、更新期限 2027-11-30）。次は DNS 設定

## 決めたこと
- アドレス：**kotopost.jp**（取得済み）
- 取得先：お名前.com（日本語・コンビニ払い可）
- 費用（税込）：取得 1円（キャンペーン）、2年目から毎年 3,124円（お名前.comの表示）。別に「サービス維持調整費」が上乗せされることがある
- 公開の仕組みは今と同じ GitHub Pages（無料）。サーバー代はかからない

## 1. オーナーがすること（購入）
1. お名前.com で `kotopost.jp` を検索して申し込む。
   - 「Whois情報公開代行」は**オン**（住所・氏名を公開しないため）
   - レンタルサーバーなどの追加サービスは**すべて外す**（不要）
   - 自動更新は**オン**（切れるとアプリが開けなくなる）
2. 取れたら、Claude に「取れた」と伝える。

## 2. オーナーがすること（設定。Claudeが一緒に案内）
1. **GitHubでドメインの持ち主を確認**（乗っ取り防止）：GitHub右上のアイコン →「Settings」→「Pages」→「Add a domain」に `kotopost.jp` → 表示された TXT の値を、お名前.com の DNS 設定に追加 →「Verify」。
2. **お名前.com の DNS 設定**（お名前.com Navi →「ネームサーバー・DNS」→「DNS設定/転送設定」→ kotopost.jp →「DNSレコード設定を利用する」）に次を追加。ネームサーバーを「お名前.comのネームサーバー（01.dnsv.jp など）」に変える案内が出たら、そのまま進める：

| 種類 | ホスト名 | 値 |
|---|---|---|
| A | （空欄） | 185.199.108.153 |
| A | （空欄） | 185.199.109.153 |
| A | （空欄） | 185.199.110.153 |
| A | （空欄） | 185.199.111.153 |
| CNAME | www | hidewaysunsetcamp-design.github.io |

3. リポジトリの「Settings」→「Pages」→「Custom domain」に `kotopost.jp` を入れて保存 → 数分〜最大48時間後に「Enforce HTTPS」にチェック。

## 3. Claude がすること
- リポジトリに `CNAME` ファイル（中身 `kotopost.jp`）を追加。
- アプリ内の紹介文・じまん画像・README・広報資料のアドレスを新しいものに差し替え。
- 新しいアドレスで全画面の動作確認（パソコンのClaude Codeに T01 と同じ確認を依頼）。

## ⚠️ 引っ越し前に必ず：データのバックアップ
アドレスが変わると、ブラウザは「別のサイト」とみなすため、**今のアドレスで記録したデータは新しいアドレスでは見えません**（GitHubが古いアドレスを新しいアドレスへ自動で転送するため、古い方も開けなくなります）。
1. 切り替えの**前に**、今のアプリで「設定」→「バックアップを書き出す」。
2. 切り替えた**あとに**、新しいアドレスで「設定」→「バックアップ・健康手帳ファイルを読み込む」。
- 外平先生や試してくださった方にも、切り替え日の前に同じお願いをする（体験版だけの方は不要）。
